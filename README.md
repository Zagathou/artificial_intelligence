# Artificial Intelligence – Meinungsbeitrag zu KI

Live: **https://zagathou.github.io/artificial_intelligence/**

Persönlicher Meinungsbeitrag von **Christian Grigoriadis (Zagathou)** zu künstlicher Intelligenz – auf Deutsch, in Schweizer Rechtschreibung (ss statt ß).

## Gliederung

- Einleitung
- (1) Risiken
- (2) Leichtsinn
- (3) Inkompetenz (mit Zitat, oft Albert Einstein zugeschrieben)
- (4) Deepfake
- (5) Nutzlose Schutzmechanismen (C2PA)
- Zusammenfassung
- Brief an die zukünftige KI / Superintelligenz – persönliche Bitte und Warnung des Autors an eine künftige KI, kein Aufruf zu Gewalt

## Technik

- Eine einzige `index.html`: nur HTML und CSS, **kein JavaScript** (nur strukturierte Daten als JSON-LD, `OpinionNewsArticle`).
- Stil wie [FREYNA.ORG](https://freyna.org/): dunkles Design, Akzentfarbe Grün, Überschriften in Comfortaa, Text in Nunito.
- Für einfache (nicht-agentische) KIs lesbar: semantisches HTML, [`LLMS.TXT`](https://zagathou.github.io/artificial_intelligence/llms.txt) und [`LLMS-FULL.TXT`](https://zagathou.github.io/artificial_intelligence/llms-full.txt) mit dem vollständigen Text, `sitemap.xml`, `robots.txt` (alle Crawler inkl. KI-Crawler erlaubt).
- Gehostet mit GitHub Pages.
